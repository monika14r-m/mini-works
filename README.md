# SayCheeze

A browser-based photo booth application that enables webcam capture, image editing, custom layouts, visual effects, and instant photo strip generation.

## Overview

SayCheeze brings the photo booth experience to the web, allowing users to capture photos from their camera or upload existing images, apply creative filters, customize frames and captions, and export polished photo strips directly from the browser.

## Features

* Webcam photo capture
* Image upload support
* Single-photo and photo-strip layouts
* 20+ cinematic, vintage, and artistic filters
* Custom Polaroid frame styles
* Caption and text customization
* Brightness, contrast, and saturation controls
* Real-time preview and editing
* Client-side image processing
* Downloadable final compositions

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Canvas API
* MediaDevices API

## Getting Started

```bash
git clone https://github.com/monika14r-m/SayCheeze.git

cd SayCheeze
```

Open `index.html` in your browser or run:

```bash
npx serve .
```
